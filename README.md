# Address Book in C

A console-based contact management application written in **C**. It demonstrates structured data, menu-driven program design, input validation, and file handling.

## Features
- Add, search, edit, and delete contacts
- Organize contact details using C structures
- Menu-driven command-line interface

## Concepts Practised
- Structures and functions
- String handling and input validation
- File I/O and modular C programming

## Getting Started
Compile the source files with GCC from the project directory. If the repository includes a Makefile, use the build instructions provided there.

## Project
**Language:** C  
**Focus:** Core C programming and data management
